# 007 Advent Wheel

Instalowalna aplikacja PWA na Androida. Wersja 2026 zawiera 24 filmy EON od *Doktora No* do *Spectre*. *Nie czas umierać* jest wyłączone z puli.

## Uruchomienie lokalne
Otwórz `index.html` w przeglądarce, aby przetestować podstawowe działanie. Instalacja PWA i tryb offline wymagają hostingu przez HTTPS (albo localhost).

## Publikacja i instalacja na Androidzie
1. Umieść wszystkie pliki z tego folderu na hostingu obsługującym statyczne strony i HTTPS (np. GitHub Pages).
2. Otwórz adres strony w Chrome na Androidzie.
3. Wybierz menu ⋮ → „Zainstaluj aplikację” lub „Dodaj do ekranu głównego”.
4. Uruchom ikonę 007 Advent z ekranu głównego.

Postępy są przechowywane lokalnie w przeglądarce/na urządzeniu. Wyczyszczenie danych witryny może je usunąć. Nie ma konta ani synchronizacji między urządzeniami.

## Ważne
To fanowska, nieoficjalna aplikacja. Nie jest powiązana z EON Productions, MGM ani właścicielami marki James Bond.
